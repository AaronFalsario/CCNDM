# CCNDM — Columban College Nursing Discipline Monitoring

A React + Vite web app for tracking student disciplinary records and community service.

## Features
- Student portal (login, penalties, appeals, schedule)
- Admin dashboard (manage students, penalties, appeals)
- Dark mode + responsive layout

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Supabase (auth + database)
- React Router

## Setup
1. Clone the repo
2. `npm install`
3. Create `.env` with:
   VITE_SUPABASE_URL=...
   VITE_SUPABASE_ANON_KEY=...
4. `npm run dev`
